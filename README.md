# Shorts Subscriber Studio — ClarioHub Worldwide

## Run locally
1. Install dependencies: `pip install -r requirements.txt`
2. Set environment variable `CLARIOHUB_API_KEY` or add it to Streamlit Secrets.
3. Run: `streamlit run app.py`

Streamlit Secrets example:
```toml
CLARIOHUB_API_KEY = "your-key-here"
```

Select **Worldwide / pilih bahasa** for culturally neutral global humor, or select a country and language to adapt the story and video/thumbnail prompts. The original app structure and story workflow are retained.
